# ES2023（ES14）

## 数组扩展 

ES14 引入了三种新的数组方法。这些方法为修改原始数组的现有数组方法提供了非变异替代方法

toReversed()

toSpliced()

toSorted()



```javascript
const arr = [1, 2, 3, 4, 5];

console.log(arr.toReversed()); // [5, 4, 3, 2, 1]
console.log(arr); // [1, 2, 3, 4, 5] - original array remains unchanged

console.log(arr.toSpliced(1, 2, "a", "b")); // [1, 'a', 'b', 4, 5]
console.log(arr); // [1, 2, 3, 4, 5] - original array remains unchanged

console.log(arr.toSorted((a, b) => b - a)); // [5, 4, 3, 2, 1]
console.log(arr); // [1, 2, 3, 4, 5] - original array remains unchanged

```



ES14 引入了两个新方法 `findLast` 和 `findLastIndex` ，它们允许从数组的最后一个位置查找元素

```javascript
console.log(arr.findLast((x) => x % 2 === 0)); // 4
console.log(arr.findLastIndex((x) => x % 2 === 0)); // 3
```



## Symbols作为WeakMap唯一键

使用 ES14，现在可以在 WeakMap 中使用 Symbols 作为键。Symbols 具有唯一的标识，使其适合唯一的键。

```javascript
const keyA = Symbol("keyA");
const keyB = Symbol("keyB");

const map = new Map();
map.set(keyA, "A");

console.log(map.get(keyA)); // Output: 'A'
console.log(map.get(keyB)); // Output: undefined

```
