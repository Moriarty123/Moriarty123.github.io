# 高阶函数

什么是高阶函数？一类以函数作为参数或把函数作为返回值的函数
为什么需要高阶函数？将函数实现抽象，专注于预定的目标，而不关注底层逻辑

## 闭包与高阶函数

什么是闭包？闭包（closure）是一个函数以及其捆绑的周边环境状态（lexical environment，词法环境）的引用的组合。换而言之，闭包让开发者可以从内部函数访问外部函数的作用域。在 JavaScript 中，闭包会随着函数的创建而被同时创建。简单来说，闭包是一个内部函数。
闭包可以使高阶函数更加灵活

## 闭包在高阶函数中的应用

一些实用的高阶函数

### 1.接受参数并返回另一个函数的函数

```javascript
// 接受参数value，返回执行fn的函数
const tap = (value) => {
  return (fn) => {
    typeof fn === "function" && fn(value);
  };
};
const arr = [1, 2, 3];
arr.forEach((item) => {
  const fn = (a) => console.log(a);
  tap(item)(fn);
});
// 1 2 3
```

### 2.将多参数函数转为一个参数的函数

```javascript
// fn.length 表示函数参数的个数，不为1时转化为一个参数的函数
const unary = (fn) => {
  return fn.length === 1 ? fn : (args) => fn(args);
};

const arr = [1, 2, 3];

// parseInt是两个参数的函数
console.log(arr.map(parseInt));
// [1, NaN. NaN]

// unary(parseInt))转为一个参数的函数
console.log(arr.map(unary(parseInt)));
// [1,2,3]
```

### 3.只执行一次的函数

```javascript
// 定义一个变量，第一次执行后置为true，下次调用不会执行
const once = (fn) => {
  let done = false;
  return () => {
    if (done) {
      return;
    }
    done = true;
    fn.apply(this, arguments);
  };
};

// 模拟想要只执行一次的函数
const pay = once(() => {
  console.log("pay");
});

// 调用两次pay。只执行第一次
pay();
pay();
// pay
```

### 4.缓存已计算过的值，避免重复计算，提供效率

优点是不会影响到传入的函数

```javascript
// 使用记忆的方式产生的新函数
const memoized = (fn) => {
  const table = {};
  return (arg) => {
    // 有缓存值取缓存，没有则计算后缓存再返回
    return table[arg] ? table[arg] : (table[arg] = fn(arg));
  };
};

// 阶乘函数
const factorial = (n) => {
  if (n === 0) {
    return 1;
  }
  return n * factorial(n - 1);
};

// 为阶乘参数套上memoized
const newFunc = memoized(factorial);

// 使用阶乘函数，结果为120
console.log(newFunc(5));
// 使用新函数，结果为120，效率比普通阶乘高
console.log(factorial(5));
```

### 5.合并对象的函数，Object.assign的实现思路

```javascript
// 合并对象的函数，遍历参数，添加所有key
const objectAssign = (target, ...sources) => {
  for (let source of sources) {
    for (let key in source) {
      if (source.hasOwnProperty(key)) {
        target[key] = source[key];
      }
    }
  }
  return target;
};

const a = { a: 1, aa: "2", aaa: 5.0 };
const b = { b: 2, bb: "ca" };
const c = { c: "cc" };

console.log(objectAssign(a, b));
console.log(objectAssign({}, a, b, c));
```
