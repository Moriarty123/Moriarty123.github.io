函数式调用弹窗组件

March 29, 2025 · 2 min read

为什么要使用函数式调用​

组件在没有使用时不会挂载，不会占用内存，并且父组件中没有对子组件的维护逻辑，代码更简洁。

我的想法是组件只在需要时才动态挂载，相应逻辑都可以放在函数体中处理。

实现的思路​

写一个hook函数，传入组件及组件的props，动态渲染该组件

主要代码​

useComponent.js​

import { createApp } from "vue";
import ElementPlus from "element-plus";
import "element-plus/dist/index.css";

const useComponent = (Component, options) => {
  const mountNode = document.createElement("div");
  document.body.appendChild(mountNode);

  return new Promise((resolve, reject) => {
    let app = createApp(Component, {
      ...options,
      close: () => {
        app.unmount();
        mountNode.remove();
        app = undefined;
        reject();
      },
      submit: (list) => {
        app.unmount();
        mountNode.remove();
        app = undefined;
        resolve(list);
      },
    });

    if (app) {
      app.use(ElementPlus).mount(mountNode);
    }
  });
};
export default useComponent;

代码解释​

这里使用createApp来创建一个vue实例，所以实际开发中，在main.js文件引入的三方件这里都要引入。

首先创建一个div元素放在body下，用于挂载组件。函数返回一个Promise,用于回调，接收两个参数，第一个是组件，第二个是组件的prop。

createApp函数除了options外还加了close和submit,用于移除组件，顺序是先卸载，然后移除div，再然后置空app,最后进行resolve和reject的回调

如何使用​

在父组件中引入useComponent函数

App.vue​

<template>
  <el-button @click="openDialog">点击打开弹窗</el-button>
</template>

<script>
import CustomDialog from "./components/CustomDialog.vue";
import useComponent from "./hooks/useComponent";

export default {
  name: "App",
  methods: {
    openDialog() {
      useComponent(CustomDialog, {});
    },
  },
};
</script>

CustomDialog.vue​

<template>
  <el-dialog v-model="visible" title="自定义dialog" width="482">
    <el-form label-position="top">
      <el-form-item label="姓名">
        <el-input></el-input>
      </el-form-item>
      <el-form-item label="年龄">
        <el-input></el-input>
      </el-form-item>
    </el-form>
    <template #footer>
      <el-button @click="close">取消</el-button>
      <el-button type="primary" @click="submit">确定</el-button>
    </template>
  </el-dialog>
</template>

<script setup>
import { ref, defineExpose, onMounted } from "vue";

const visible = ref(false);

const open = () => {
  visible.value = true;
};

const close = () => {
  visible.value = false;
};

const submit = () => {
  new Promise((resolve) => {
    setTimeout(() => {
      resolve();
    }, 1000);
  }).then(() => {
    console.log("submit success");
  });
};

const init = () => {
  open();
};

onMounted(init);

defineExpose({
  open,
  close,
});
</script>
